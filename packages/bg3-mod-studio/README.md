# Baldur's Gate 3 Mod Studio (`bg3-mod-studio`)

Metapackage stub that installs the complete Baldur's Gate 3 Mod Studio tooling suite:
- `bg3-core`: Shared runtime, LSF/LSPK parsers, mod.io client, load order manager, and save inspector.
- `bg3-authoring`: Custom mod authoring, stat scaffolding, diagnostics, and packaging toolkit.
- `bg3-theorycraft`: Modded character build crafting and gear recommendation engine.

## Installation

```bash
pip install bg3-mod-studio
# or
uv tool install bg3-mod-studio
```

## Usage

```bash
bg3 --help
```
