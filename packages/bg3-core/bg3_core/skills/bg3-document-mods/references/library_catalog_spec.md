# Library Catalog Specification & Categories

## 1. Six-Column Schema (`mods/library.md`)

Each cataloged mod row contains:
1. **Mod Id**: Verified numeric mod.io ID.
2. **Mod Name**: Formatted name of the mod.
3. **Mod Slug**: Workspace folder slug.
4. **Description**: Concise summary of mod features.
5. **Features Documented**: Quantified count of implemented features.
6. **Spec Link**: Relative markdown link to `mods/<slug>/README.md`.

---

## 2. Catalog Categories

Mods are partitioned into 5 standardized markdown tables:
- **Gear**: Weapons, armor, jewelry, vanity equipment.
- **Spells**: Cantrips, level 1–9 spells, spell overhauls.
- **Classes & Subclasses**: Classes, subclasses, custom progression trees.
- **Progression & Rules**: Level cap extensions, feat intervals, stat curve mods.
- **Utilities & Cheats**: Quality of life, convenience containers, respec tools.
